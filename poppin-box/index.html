Tentang Kami

Kurasi Hangat untuk Kolektor Blind Box

Poppin Box hadir sebagai toko spesialis blind box yang menjaga keaslian segel pabrik, kondisi kotak mulus, serta pengalaman belanja personal langsung lewat WhatsApp tanpa proses rumit.

01

Segel Utuh

Semua kotak dikirim dalam kondisi tersegel rapi untuk menjaga keseruan unboxing.

02

Packing Aman

Gratis lapisan bubble wrap tebal dan kardus pelindung agar sudut box tidak penyok.

03

Admin Responsif

Konfirmasi stok real-time dan cek foto resi langsung melalui chat WhatsApp.

Metode Pembayaran & Cara Pesan

Pilih metode pembayaran favoritmu saat checkout di keranjang sebelum mengirim pesan WhatsApp.

QRIS Instan

Rekomendasi

Mendukung pembayaran instan dari seluruh aplikasi e-wallet (GoPay, OVO, DANA, ShopeePay) dan mobile banking. Kode QRIS resmi dikirim oleh admin setelah konfirmasi stok.

COD (Bayar di Tempat)

Area Tertentu

Bayar tunai langsung ke kurir saat paket tiba. Tersedia untuk pengiriman reguler di wilayah terjangkau setelah verifikasi alamat melalui WhatsApp.
